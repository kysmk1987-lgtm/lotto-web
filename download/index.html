바로 사용하기 (설치 없이) 웹 앱 열기

크롬/삼성 인터넷 메뉴의 홈 화면에 추가(아이폰 사파리: 공유 → 홈 화면에 추가)를 누르면 앱처럼 쓸 수 있습니다.

안드로이드 앱 (APK) APK 다운로드 (대부분의 휴대폰) 구형 32비트 휴대폰용
  1. 다운로드가 끝나면 알림 또는 내 파일 → 다운로드에서 APK를 누릅니다.
  2. "출처를 알 수 없는 앱" 안내가 나오면 설정 → 이 출처 허용을 켜고 설치를 누릅니다.
  3. Play 프로텍트 경고가 나오면 세부정보 → 무시하고 설치를 누릅니다 (개인 배포 앱이라 표시됩니다).

아이폰은 APK를 설치할 수 없으니 위의 웹 앱을 이용하세요.

본 앱의 추천은 과거 통계 기반 참고용이며 당첨을 보장하지 않습니다. 로또 추첨은 매 회 독립적인 무작위 시행입니다. 구매·베팅 기능은 없습니다.
